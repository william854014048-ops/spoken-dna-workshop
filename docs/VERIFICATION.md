# 验证说明

本项目区分真实第三方调用、本地实际执行和模拟模型响应。

## 真实第三方调用

曾完成一条公开抖音视频的真实链路：起零解析 → 下载媒体 → FFmpeg 提取音轨 → 硅基流动 SenseVoice 转写。

真人样例原文、链接导入记录、个人配置、真实转写截图与本机历史交付文件不随公共仓库发布。

## 本地自动检查

`python -B -m unittest discover -s tests -v` 覆盖：

- 分享文案提链、两平台地址识别、归一化去重与无效地址拒绝。
- Windows 凭据加密、读取、仅会话保存与清除。
- 项目内环境文件与显式外部配置的读取，关闭复用后的行为。
- 图文拒绝、空转写、上游鉴权错误与超时的脱敏处理。
- 实际生成 181 秒音频并由 FFmpeg 分成两段。
- 模拟解析／转写返回，但实际运行独立队列、单项失败与重试、修改与初始转写保留。
- 下载中断与服务重启后的临时媒体清理。
- 本机 HTTP 配置读写、请求来源限制及私密路径拒绝。

第三方响应在队列检查中模拟，因此不消耗真实 API 额度。Windows 专属 DPAPI 检查会在其他系统跳过。

## 页面回归

`npm run test:browser` 在隔离服务上运行真实页面，拦截解析／转写／写作上游响应，本地 DNA、工作区文件与加密配置读写不模拟。重构后的完整回归共 23 组行为，覆盖：

1. 三个主页面和原有布局入口。
2. 两类独立密码框与配置提交。
3. 混合批次、重复提示和待处理状态。
4. 成功／失败项并存及单项重试。
5. 查看／修改转写原文并加入原稿，且不直接生成 DNA。
6. 原稿列表查看和编辑。
7. 原有文本批量导入和逐篇添加。
8. 五篇原稿进入原有分析流程并保存 DNA 库。
9. 口述成稿与独立核对。
10. 去 AI 味调用与结果。
11. 实际导出的项目备份不含三类测试密钥。
12. 备份恢复、刷新与原稿持久化。
13. 390 像素窄屏与脚本异常检查。

新增回归包括批量成功项按作者进入文章库、作者素材与分析分别保留、按风格保存第二份 DNA、整份选择与同类型替换、跨作者组合实际进入生成请求、一键清理、三版显示、失败保全及清缓存后的工作目录恢复。页面保留设计变量与原有风格，流程改为左侧 DNA 库与三步主界面。

## 本地目录、网络兼容与限流回归

新增检查包括：5 位模拟博主、每位 10 篇原稿的独立文件保存；重建服务后读取全部 5 份；中文路径和 UTF-8 回读；不覆盖损坏资料；保存 API 设置不丢 DNA 目录；凭据字段过滤。

后端共 28 项检查。其中 50 条混合链接批次使用模拟上游响应，实际经过本地队列、写入状态与临时文件清理；没有一次性请求 50 条真实付费视频。新增工作区的 UTF-8 回读、组合与历史恢复、凭据过滤、损坏文件保护和旧版本冲突检查。

## 统一配置与目录选择

- 三项密钥、写作地址与模型在同一个工作目录分别存入 `config.json`、Windows DPAPI `credentials.dpapi`，DNA 存入 `DNA/`。重建配置对象和另一个项目副本连接已有工作目录，都能恢复配置与密钥。
- 新界面只读显示路径，点击按钮调用系统目录选择器；取消不改配置。页面回归在隔离服务中替换选择结果，仍真实执行目录连接、配置保存和加密读写；真实系统选择器另行启动并返回了测试目录。
- ASR 模型固定为 SenseVoiceSmall；客户端试图修改也不会改变。写作代理读取已保存的 Key 和模型，不返回已保存密钥。
- 无关或损坏的 config.json 不会被覆盖；旧 DNA 和原目录文件保留。目录选择不会清掉正在填写、尚未保存的密钥。
- 设置弹框不撑开主页面，支持关闭、Esc，以及桌面／390 像素窄屏；清空浏览器缓存后仍能恢复配置和 DNA。

网络检查覆盖已知 CDN 的 Fake-IP 映射、真实私网／回环和不安全重定向拒绝，以及 DNS 失败单独提示。限流检查使用模拟 429，验证共享单通道、自动退避、数字／日期形式的 Retry-After、无效密钥不盲目重试及日额度耗尽提示；没有故意耗尽真实账号额度。

此前分享链接曾真实完成解析、媒体下载、音轨提取和转写。本轮又验证了一条此前被拦的下载跳转：允许已知 `smtcdns.com` CDN 使用 Fake-IP 后，真实返回 HTTP 206、video/mp4、读取 1024 字节；本轮没有对它再次调用语音识别。仍拒绝该域名解析到真实私网及伪造后缀的情况。

真实样例的解析响应没有作者字段，公开分享页也未提供可用作者身份。本版仅在接口明确提供作者时自动分类；否则标记待确认，并允许一次指定作者批量归类。自动作者识别并非所有链接都能成功。分组、组合与新写作流程的模型响应使用模拟，不能宣称真实写作质量已验收。

## 未验证

小红书真实视频端到端调用、长真人视频、真实写作模型的产出质量、其他操作系统的完整使用流程尚未验收。模拟通过不能代表这些效果已经验证。
