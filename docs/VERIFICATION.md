# 验证说明

本项目区分真实第三方调用、本地实际执行和模拟模型响应。

## 真实第三方调用

曾完成一条公开抖音视频的真实链路：起零解析 → 下载媒体 → FFmpeg 提取音轨 → 硅基流动 SenseVoice 转写。

真人样例原文、链接导入记录、个人配置、真实转写截图与本机历史交付文件不随公共仓库发布。

## 本地自动检查

`python -B -m unittest discover -s tests -v` 覆盖：

- 分享文案提链、两平台地址识别、归一化去重与无效地址拒绝。
- Windows 凭据加密、读取、仅会话保存与清除。
- 项目内环境文件与显式外部配置的读取，关闭复用后的行为。
- 图文拒绝、空转写、上游鉴权错误与超时的脱敏处理。
- 实际生成 181 秒音频并由 FFmpeg 分成两段。
- 模拟解析／转写返回，但实际运行独立队列、单项失败与重试、修改与初始转写保留。
- 下载中断与服务重启后的临时媒体清理。
- 本机 HTTP 配置读写、请求来源限制及私密路径拒绝。

第三方响应在队列检查中模拟，因此不消耗真实 API 额度。Windows 专属 DPAPI 检查会在其他系统跳过。

## 页面回归

`npm run test:browser` 在真实页面上拦截上游响应，检查 13 组行为：

1. 三个主页面和原有布局入口。
2. 两类独立密码框与配置提交。
3. 混合批次、重复提示和待处理状态。
4. 成功／失败项并存及单项重试。
5. 查看／修改转写原文并加入原稿，且不直接生成 DNA。
6. 原稿列表查看和编辑。
7. 原有文本批量导入和逐篇添加。
8. 五篇原稿进入原有分析流程并保存 DNA 库。
9. 口述成稿与独立核对。
10. 去 AI 味调用与结果。
11. 实际导出的项目备份不含三类测试密钥。
12. 备份恢复、刷新与原稿持久化。
13. 390 像素窄屏与脚本异常检查。

源码拆分保持三个原脚本的加载顺序，核心表达分析与口述引擎内容保持；页面样式和主体元素标识保留。

## 未验证

小红书真实视频端到端调用、长真人视频、真实写作模型的产出质量、其他操作系统的完整使用流程尚未验收。模拟通过不能代表这些效果已经验证。
